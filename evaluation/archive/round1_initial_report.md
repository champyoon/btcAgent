- #5/#6은 코드는 고쳤지만 AWS 일일 토큰 쿼터에 막혀 전체 20문항 재실행으로 최종 확인을 못함 — round2에서 반드시 재확인.
- 지금까지는 규칙 기반 `judge()`(문자열 포함 여부, 도구 호출 여부)만 썼는데, Day9 요구사항인 **LLM-as-Judge**를 아직 추가하지 못함 — round2 전에 추가 예정.

- `route_question`의 키워드 목록이 아직 좁다 — 이번에 드러난 "현재가"/"rsi 정의" 유형처럼, 앞으로도 비슷한 사각지대가 더 있을 수 있다.
